# 설계 근거 정비 자료

실제 작업 폴더에서 ShopIndexController의 잘못 줄인 경로를 현재 등록 소스 경로로 수정했다. 현재 없는 구현 파일을 인용한 표기 62개는 구현·이관 누락 확인 대상으로 기록했다. 사람 확인·SR 승인·QA 완료를 새로 만들지 않았다. 기존 미커밋 SR-201 파일 두 개는 보존했다.

`workspace-overlay.zip`은 작업 폴더 커밋의 변경 파일 6개를 원래 바이트로 보관한 감사 스냅샷이다. `manifest.json`과 압축 안의 매니페스트가 파일별 지문을 담는다. 인증 설정·토큰·DB·다른 작업자의 미커밋 문서는 포함하지 않는다. 별도 기반의 작업 폴더에는 `tools/repair_source_integrity.py`로 현재 소스와 문서를 재점검해 정비안을 적용한다. 이 스냅샷을 임의의 다른 작업 폴더에 덮어쓰는 설치 방식은 제공하지 않는다.

`../source-integrity-20261024.json`은 실제 적용 결과다. 파일 연결은 전체 업무 동작의 입증이 아니며, 현재 없는 OAuth·상품카드 V2 구현은 후속 검토가 필요하다. 다른 이름의 v1 코드에 연결하지 않았다.
