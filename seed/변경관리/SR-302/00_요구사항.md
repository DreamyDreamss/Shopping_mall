# SR-302 — 커머스 홈(메인) 화면 신규 — GNB·기획 배너·카테고리·추천 상품·랭킹

> 생성: 2026-09-16 · 출처: 로컬(SpecLens)

## 요구 요지

## 요구 요지

쇼핑몰 메인 화면을 만든다(상용 홈쇼핑 사이트 수준의 정보 구조, 디자인 자산은 자체 제작). 구성은 위에서부터: ① 상단 GNB(로고, 카테고리 메뉴, 검색 입력, 장바구니 아이콘+담긴 수량, 로그인/마이) ② 히어로 배너 캐러셀(자동 넘김·좌우 이동·현재 위치 표시) ③ 카테고리 숏컷(아이콘+이름 가로 배열) ④ 추천 상품 그리드(상품 카드: 썸네일·상품명·판매가·정가·할인율·품절 배지) ⑤ 랭킹 섹션(탭으로 기준 전환, 순위 숫자 표시) ⑥ 최근 본 상품(브라우저 저장, 없으면 안내 문구) ⑦ 푸터(사업자 정보·고객센터·약관 링크 영역).

상품 데이터는 GET /api/products 응답을 쓴다. 이미지가 없는 상품은 대체 영역(이니셜·회색 박스)으로 채운다.

## 범위

- 대상 화면/API/테이블(짐작 가능한 만큼): shop-web 신규 화면(`/shop` 홈), 상품 카드·배너·랭킹 부품, GET /api/products
- 로그인 상태에 따라 GNB 우측 표시가 달라진다(로그인/마이)

## 제약·유의

- 기존 주문 목록·상세·로그인 화면 동작 불변, 기존 API 계약 변경 없음
- 부품마다 스토리(빈 목록·로딩·오류·품절 포함)를 만든다(프로젝트 규칙 story-per-component)
- 부품에서 직접 fetch 금지(규칙 web-fetch-only-in-api), console.log 금지
- 상용 사이트의 로고·상품 이미지·문구를 그대로 쓰지 않는다(레이아웃·정보 구조만 참고)

- **Q. 빈 값·오류 상태의 화면 표기는 무엇인가?**
