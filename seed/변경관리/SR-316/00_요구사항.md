# SR-316 — 상품 상세 레이아웃 — 미디어 캐러셀·혜택/배송 블록·스티키 탭·구매 하단 시트

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N08 · 에픽 UI/UX · 유형 화면 · Wave 1
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

상품 상세를 KT알파쇼핑 구성으로 바꾼다: 상단 배지·상품명·별점/상품평 수·공유, 미디어 캐러셀(이미지+영상, n/N), 방송 정보 블록 자리, 가격 블록(판매가·'나의 최대 혜택가' 자리·무이자 할부 자리), 배송 정보 블록(택배사·배송비·배송불가 지역·도착 예정 자리), 태그 줄, 스티키 탭(상세정보·구매정보·상품평·상품문의), 우측 레일 고정 구매 영역([선물하기] 자리·[구매하기]) → 하단 시트(수량 스테퍼·행 금액·주문금액·[장바구니][바로구매]).

## 배경

벤치마크 §5(상품 상세) 구성을 레이아웃으로 먼저 고정한다(기존 SR-304 화면의 리스킨). SR-244의 UI/UX 요구(하단 고정 구매·탭 스크롤 스파이)를 이 SR로 분리하고, 각 자리의 데이터는 후속 SR이 채운다.

## 범위

- 포함:
  - 레이아웃과 블록 자리(값 없는 블록은 숨김), 미디어 캐러셀(스와이프·확대), 탭 스티키·스크롤 스파이, 구매 하단 시트(공통 BottomSheet), 우측 레일 구매 영역(앱 셸 우측 레일 슬롯).
- 제외:
  - 다중 이미지·태그 데이터, 방송 정보, 무이자, 옵션(SR-245), 좋아요(SR-243), 도착 예정일(SR-244 잔여), 선물하기, 혜택가.

## 수용 기준

- [ ] 탭 바가 스크롤 시 상단에 붙고 탭을 누르면 해당 섹션으로 이동하며 스크롤 위치에 따라 활성 탭이 바뀐다
- [ ] [구매하기]를 누르면 하단 시트가 열리고 수량 변경 시 주문금액이 즉시 갱신되며 [장바구니]가 기존 담기 API로 동작한다
- [ ] 값이 없는 블록(방송·무이자·태그 등)은 제목까지 숨겨진다
- [ ] 이미지가 1장이면 페이지 표시(n/N)를 숨기고 0장이면 대체 영역을 보인다
- [ ] 품절 비활성(SR-216)·담기 후 장바구니 수량 즉시 반영이 유지된다
