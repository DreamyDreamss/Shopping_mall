# SR-343 — 행동 이벤트 수집 — 상품 조회·검색·담기·주문 전환 로그

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N35 · 에픽 비기능 · 유형 API+DB · Wave 3
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

상품 조회·검색어·장바구니 담기·주문 완료 이벤트를 USER_EVENTS에 적재하는 수집 API를 만든다. 인기 검색어(SR-239), 전환율(SR-283), 프로모션 성과(SR-274), 연관 상품(SR-250)의 원천이다.

## 배경

대시보드·인기 검색어·추천 SR이 모두 '노출·조회' 데이터를 요구하지만 지금은 주문 데이터밖에 없다.

## 범위

- 포함:
  - POST /api/events(배치 전송, 비로그인은 익명 ID), 이벤트 타입 4종·스키마, 서버 측 주문 완료 이벤트 기록, 보존 90일, 개인정보 최소화(IP 미저장).
- 제외:
  - 집계 배치(SR-274·283), 실시간 스트리밍, 외부 분석 도구.

## 수용 기준

- [ ] 상품 상세 진입·검색·담기·주문 완료 시 이벤트가 각각 1행 기록된다
- [ ] 이벤트 전송 실패가 화면 동작을 막지 않는다
- [ ] 비로그인 이벤트는 익명 ID로, 로그인 후 이벤트는 회원 ID로 기록된다
- [ ] 90일 지난 이벤트가 정리 배치로 지워진다
