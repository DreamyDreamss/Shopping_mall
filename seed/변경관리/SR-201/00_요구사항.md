# SR-201 요구사항

## 개요
- **SR 제목**: 상품 카탈로그 화면 신설 (상품 목록 + 상품 상세)
- **요청자**: 운영기획팀 김보라
- **우선순위**: High
- **목표 일정**: 2026-09-05

## 변경 배경 및 목적
현재 상품 정보는 시스템에 등록되어 있지만 **화면이 없어** 운영자가 상품 현황(가격·재고·품절 여부)을
확인하려면 개발팀에 요청하거나 API를 직접 호출해야 한다. 주문 목록/상세 화면은 이미 있으므로,
같은 톤앤매너로 상품을 조회할 수 있는 화면을 신설해 운영 자립도를 높인다. (쇼핑몰 확장 1단계 —
이후 장바구니·체크아웃 개편의 기반 화면이 된다.)

## 요구사항 상세

### 기능 요구사항
- **상품 목록 화면 신설** (`/product/list` 수준의 메뉴 접근)
  - 표 형태: SKU, 상품명, 가격, 재고 수량, 상태(판매중/품절)
  - **상품명 키워드 검색**을 지원한다 (부분 일치).
  - 재고가 0인 상품은 상태를 "품절"로 표시한다.
  - 행(상품명)을 클릭하면 상품 상세 화면으로 이동한다.
- **상품 상세 화면 신설**
  - SKU, 상품명, 가격, 재고 수량, 상태, 등록일을 표시한다.
  - 목록으로 돌아가는 링크를 둔다.
- 목록 화면은 주문 목록 화면과 같은 테이블 스타일을 따른다.

### 비기능 요구사항
- 조회 전용(등록·수정 없음 — 이번 단계 범위 밖).
- 상품 100건 기준 목록 로딩 1초 이내.
- 별도 권한 없음(사내망 운영자 화면 — 기존 화면들과 동일).

## AS-IS 현황
- 상품 데이터 조회 API는 있는 것으로 안다(개발팀 확인 필요). 화면은 없음.
- 상품명 검색은 현재 어떤 방법으로도 불가.

## TO-BE 목표
- 메뉴(또는 URL 직접 접근)로 상품 목록 → 상세를 오갈 수 있다.
- 목록에서 상품명 일부(예: "키보드")로 검색하면 해당 상품만 남는다.
- 품절 상품이 한눈에 구분된다.

## 영향 예상 범위 (선택)
- 화면: 신규 2개 (상품 목록, 상품 상세)
- API: 상품 조회 API에 검색 조건이 없다면 보완 필요할 수 있음 (개발팀 판단)
- DB: 변경 없음 (기존 상품 데이터 사용)

## 첨부/참고 파일 (선택)
- 없음 (주문 목록 화면을 참고 스타일로 볼 것)
