# SR-201 분석서

## SR 개요
- **SR**: SR-201 — 상품 카탈로그 화면 신설 (상품 목록 + 상품 상세)
- **SR 유형**: COMPOSITE (SCREEN_NEW ×2 + API_MODIFY ×1)
- **우선순위**: High
- **영향 도메인**: order
- **분석일**: 2026-08-22
- **인입 경로**: 로컬 요구사항 (docs/변경관리/SR-201/00_요구사항.md)

## 요구사항 요약
상품 데이터는 있으나 화면이 없어 운영자가 상품 현황(가격·재고·품절)을 확인할 수 없다.
상품 목록 화면(키워드 검색·품절 표시·상세 이동)과 상품 상세 화면을 신설하고,
목록 API에 상품명 부분일치 검색을 보완한다. 조회 전용·DB 변경 없음.

## AS-IS 실측 (Step 5 — 소스 앵커 JIT read + DB 조회)
- `GET /api/products/`(INF-ORD-008): 파라미터 없음. `product.xml selectProducts`가
  `sale_yn='Y'` 상시필터 + `ORDER BY sku`. 키워드 검색 **없음**.
- `GET /api/products/{sku}`(INF-ORD-009): 단건, 미존재 시 404 ("상품 없음: {sku}").
- 화면: 상품 관련 화면 0개 (주문 목록/상세만 존재 — UIS-ORD-001/002).
- DB `PRODUCTS` 실측 5컬럼(sku·product_name·price·stock_qty·sale_yn) — **등록일 컬럼 없음**
  → 의사결정 D1: 등록일 표시는 이번 범위 제외 (inputs/_decisions.md).

## 변경 요구사항 (SR 단일축)
- 상품 목록 화면: SKU·상품명·가격·재고·상태(재고 0 → "품절") 표, 상품명 부분일치 검색,
  행 클릭 → 상세 이동, 0건 시 "표시할 상품이 없습니다".
- 상품 상세 화면: SKU·상품명·가격·재고·상태 표시(등록일 제외 — D1), 목록 복귀 링크,
  미존재 SKU는 "상품을 찾을 수 없습니다" + 목록 링크.
- 목록 API: `keyword` 선택 파라미터(부분일치, sale_yn 필터와 AND). 미지정 시 기존과 동일.
