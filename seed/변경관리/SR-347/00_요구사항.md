# SR-347 — 선물하기 — 받는 사람 연락처로 주문·받는 사람이 배송지 입력

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N39 · 에픽 주문·결제 · 유형 화면+API+DB · Wave 3
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

상세 [선물하기]로 받는 사람 이름·연락처·메시지만 넣고 결제하면, 받는 사람에게 모의 발송함으로 링크가 가고 받는 사람이 배송지를 입력해 주문이 상품준비로 넘어간다. 7일 안에 입력하지 않으면 자동 취소된다.

## 배경

벤치마크 상세 우측 구매 영역의 [선물하기]와 마이쇼핑 '선물 메시지 관리'. 주문 상태 모델·모의 결제·발송함이 있어야 한다.

## 범위

- 포함:
  - GIFT_ORDERS(order_no, receiver_name, receiver_phone, message, token, address_entered_at, expire_at), 선물 주문서, 받는 사람 배송지 입력 화면(토큰 링크·1회용), 7일 미입력 자동 취소 배치(결제 취소 포함), 보내는 사람 주문 내역에 선물 표시.
- 제외:
  - 선물 거절·교환권 전환, 기프티쇼.

## 수용 기준

- [ ] 선물 결제 후 발송함에 받는 사람 링크가 1건 기록된다
- [ ] 받는 사람이 배송지를 입력하면 주문이 결제완료→상품준비중으로 넘어가고 링크는 다시 쓸 수 없다
- [ ] 7일 동안 입력이 없으면 주문과 결제가 취소된다(배치 재실행에도 1회)
- [ ] 보내는 사람은 받는 사람 주소를 볼 수 없다
