# SR-342 — 상품·단품 모델 분리 — 옵션 그룹 도입(SR-245 선행)

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N34 · 에픽 상품 · 유형 API+DB · Wave 3
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

하나의 상품(product_code) 아래 여러 단품(sku)을 두는 모델로 바꾼다: PRODUCT_GROUPS(상품 단위 정보)와 옵션 축(색상·사이즈) 정의, sku별 옵션값·가격·재고. 기존 sku 단위 장바구니·주문 계약은 유지한다.

## 배경

SR-245(2단 옵션 조합→단품)는 지금 모델(상품=sku 1:1)에서 불가능하다. 모델 이관을 옵션 UI와 한 SR에서 하면 한 번의 AIDD 실행 범위를 넘는다.

## 범위

- 포함:
  - 그룹·옵션 축·옵션값 테이블, 기존 상품을 단품 1개짜리 그룹으로 이관(무손실), 상세 조회 응답에 options·variants 추가, 매니페스트 옵션 필드 선택 지원.
- 제외:
  - 옵션 선택 UI·재고별 비활성(SR-245), 관리자 옵션 매트릭스(SR-279).

## 수용 기준

- [ ] 이관 후 모든 기존 sku가 단품으로 조회되고 장바구니·주문·재고 차감이 sku 단위로 그대로 동작한다
- [ ] 옵션이 있는 그룹은 상세 응답에 옵션 축과 단품별 가격·재고가 온다
- [ ] 이관 DDL·데이터 이관이 멱등이다
