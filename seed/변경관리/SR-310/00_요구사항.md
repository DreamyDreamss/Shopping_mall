# SR-310 — 공통 UI 컴포넌트 세트 — 버튼·입력·배지·탭·하단 시트·팝업·토스트·빈/오류 상태

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N02 · 에픽 UI/UX · 유형 화면 · Wave 1
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

토큰 위에 KT알파쇼핑 규격의 공통 컴포넌트를 만든다: Button(주=검정 채움·보조=흰 바탕 회색 테두리·구매=파랑→보라 그라데이션), 입력류·QuantityStepper(− 1 +), Badge(TV상품·무료 배송·무이자 N·LIVE·할인율), Tabs(스티키·스와이프 전환), BottomSheet(구매 시트), 이미지 팝업 캐러셀('오늘은 그만 보기'), Toast, Skeleton, EmptyState·ErrorState.

## 배경

기존 화면은 버튼·입력을 화면마다 새로 만들어 모양과 상태 표기가 제각각이다. 벤치마크(벤치마크 {{WS}}\_lab\plan\benchmark_ktalpha.md §1)의 버튼·배지·빈/오류 상태 규격을 부품으로 고정해 이후 화면 SR이 조립만 하게 한다. SR-289(공통 상태 UI)의 스켈레톤·빈 목록·오류·토스트 규약을 이 SR로 흡수한다.

## 범위

- 포함:
  - 위 컴포넌트와 상태별(기본·포커스·비활성·오류·로딩) 스토리, 배지 5종 규격(TV상품=검정, 무이자=테두리형, 할인율=빨강, LIVE=카운트다운 슬롯), EmptyState(가운데 라인 아이콘+한 줄 안내+테두리 버튼+하단 추천 레일 슬롯), ErrorState(원형 느낌표+'이용에 불편을 드려 죄송합니다.'+[홈으로][돌아가기]), 키보드 조작(포커스 트랩·Esc 닫기), 토스트 규약(최대 3개).
- 제외:
  - 기존 화면 교체, 데이터 연동, 팝업 운영 데이터, 오프라인 배너(SR-289 잔여).

## 수용 기준

- [ ] 모든 컴포넌트가 디자인 토큰만 참조하고 컴포넌트마다 상태별 스토리가 있다
- [ ] BottomSheet·팝업은 열릴 때 포커스가 안으로 들어가고 Esc·닫기로 닫히며 닫힌 뒤 원래 요소로 포커스가 돌아온다
- [ ] QuantityStepper는 최솟값·최댓값 경계에서 버튼이 비활성화되고 범위 밖 직접 입력은 경계로 보정된다
- [ ] 배지 5종·EmptyState·ErrorState가 벤치마크 스크린샷(bench/screenshot-10·11)과 같은 구성이다
- [ ] 컴포넌트 단위 테스트가 있고 기존 화면 테스트는 그대로 통과한다
