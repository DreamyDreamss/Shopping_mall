# SR-295 — 인증코드 재발송 시 시도 횟수 초기화(MBR-4093 회복 경로)

> 생성: 2026-09-12 · 출처: 로컬(SpecLens)

## 요구 요지

[유형: API] SR-231 FUNC-member-003 QA round 3 권고 2. attempt_count>=5로 잠긴 target은 '재발송 필요(MBR-4093)'를 받지만 INF-MBR-001 재발송(writeCode)이 attempt_count를 리셋하지 않아 영구 잠금이다. 재발송 성공 시 새 코드 행의 attempt_count=0으로 시작하고 이전 행은 폐기한다. 수용 기준: 5회 오답 잠금 → 재발송 → 새 코드로 가입 성공 · 잠금 전 코드는 재발송 후 무효.

## 범위 확장 (2026-09-12, SR-231 FUNC-member-003 QA round 4)

- 재발송 시 `attempt_count` 리셋뿐 아니라 **`consumed_at`도 리셋**(새 코드 행은 consumed_at NULL) — round 4에서 되살아난 AC 파손의 실제 원인은 consumed_at 비리셋이다. 수용 기준에 "가입 성공 후 같은 target 재발송 → 새 코드로 재검증 가능" 추가.
