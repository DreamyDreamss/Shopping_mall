# SR-209 — 주문 목록 조회기간 프리셋 버튼

> 생성: 2026-09-08 · 출처: 로컬(SpecLens)

## 요구 요지

주문 목록 화면(order/list.html)의 검색 조건에 조회 기간 프리셋 버튼(최근 7일·30일·90일)을 추가한다. 버튼을 누르면 시작일·종료일 입력값이 그 기간으로 채워지고 즉시 조회된다. 기존 시작일/종료일 직접 입력과 상태 필터 동작은 그대로 유지한다. API(INF-ORD-003) 계약은 바꾸지 않는다 — 화면에서 기존 startDate/endDate 파라미터를 채워 보낼 뿐이다.
