# SR-311 변경명세

## AS-IS → TO-BE 비교

### UIS-CMN-003 (앱 셸 — 영향 스펙 파일 경로 없음, 영향 ID만 제시됨)

- AS-IS: [미상] — 영향 스펙 파일이 제시되지 않았다. 요구사항 배경에 따르면 SR-288(반응형 3 브레이크포인트·PC 메가메뉴)이 현재 쇼핑 라우트(#/shop/**)의 레이아웃을 규정하고 있는 것으로 보이나, SR-288의 스펙 파일 자체는 이번 작업의 영향 스펙 목록에 없으므로 그 필드·구조를 대조 근거로 삼지 않는다. UIS-CMN-003이라는 ID 자체가 이번 SR에서 신규로 쓰이는 것으로 보이며, 기존에 동일 ID의 스펙이 있었는지는 [미상].
- TO-BE (요구사항·확정 문답 근거):
  - 적용 범위: shop-web 쇼핑 라우트(#/shop/**) 전체 — #/shop, #/shop/products, #/shop/products/:sku, #/shop/cart, #/shop/order, #/shop/mypage/addresses, 로그인 계열. 별도 진입점 없이 공통 적용.
  - 브레이크포인트 1200px 이상: 가운데 750px 본문 + 좌측 세로 퀵바 + 우측 레일.
  - 브레이크포인트 750px 미만: 전폭 본문 + 하단 탭바(퀵바·레일 사라짐).
  - 헤더: 로고·검색 아이콘·장바구니 수량. (검색 동작 자체는 제외 — 아래 '제외' 참조)
  - 가로 GNB 탭: 목록은 설정값 한 곳에서 관리, 탭 위 빨간 라벨, 좌우 스와이프 전환, 도착 화면 없는 탭은 숨김(현재는 '홈'과 존재하는 화면만 노출).
  - 좌측 세로 퀵바(1200px 이상): 홈·ON AIR·카테고리·마이·QR·TOP.
    - ON AIR: 지금 방송중 — SR-319 전까지는 숨김.
    - 카테고리: 서랍 진입점 — SR-237 전까지는 숨김(서랍 내용 자체는 제외).
    - QR: 현재 페이지 URL을 담은 QR 팝업.
    - TOP: 클릭 시 맨 위로 스크롤.
  - 하단 탭바(750px 미만): 홈·카테고리·ON AIR·마이.
  - 우측 레일(1200px 이상): 최근 본 상품 카드(기존 localStorage 재사용, 보라→파랑 그라데이션 헤더, 0개면 카드 숨김) + 보유 쿠폰/주문 내역 수 카드(값 없으면 카드 숨김 — 비로그인·데이터 없음 포함).
  - 푸터: 사업자 정보 자리만 마련(내용 채움은 SR-329).
  - 토큰·컴포넌트 재사용: SR-309 디자인 토큰, SR-310 공통 컴포넌트를 사용.
  - 부팅 리다이렉트(/shop → #/shop) 규약은 유지.
  - 기존 쇼핑 화면(홈·상품 목록·상세·장바구니·주문서·로그인·배송지)은 셸이 감쌀 뿐 내부 동작·라우트·테스트는 변경하지 않는다.

## 제외(변경 없음 명시)

- 카테고리 서랍 내용(SR-237) — 이번 SR은 퀵바에서 서랍을 여는 진입점만 두고, 서랍 안의 카테고리 목록·동작은 다루지 않는다(요구사항 범위·확정 문답 scope_freeze 근거).
- 검색 동작(SR-239) — 헤더에 검색 아이콘 자리만 두고 검색 실행·결과 화면은 다루지 않는다(요구사항 범위·확정 문답 scope_freeze 근거).
- 쿠폰 수 데이터(SR-276) — 우측 레일에 쿠폰 카드 자리만 두고, 쿠폰 수를 채우는 데이터 연동은 다루지 않는다(요구사항 범위·확정 문답 scope_freeze 근거).
- 헤더 '기프티쇼' 토글 — 기프티쇼 사업이 범위 밖이라 헤더에 토글을 두지 않는다(요구사항 범위 근거).
- 기존 주문 목록(#/, #/orders/*, Thymeleaf 운영 화면) — 셸을 적용하지 않고 그대로 둔다(확정 문답 scope_freeze·regression_keep 근거).
- 백엔드 — 화면 레이아웃 SR로 DB·API 변경이 없다(확정 문답 db_ripple·db_migration 근거).
- 기존 쇼핑 화면(홈·상품 목록·상세·장바구니·주문서·로그인·배송지)의 화면 내부 리스킨 — 셸이 감쌀 뿐 내부는 바꾸지 않는다. 리스킨은 SR-322·326에서 다룬다(확정 문답 regression_keep 근거).

## 회귀 범위

- 기존 쇼핑 화면(홈·상품 목록·상세·장바구니·주문서·로그인·배송지)의 동작·라우트·테스트가 불변이어야 한다 — 셸은 감싸기만 하고 화면 내부를 바꾸지 않는다(리스킨은 SR-322·326의 몫).
- 부팅 리다이렉트(/shop → #/shop) 규약을 유지한다.
- 기존 주문 목록 라우트(#/, #/orders/*, Thymeleaf 운영 화면)는 셸 적용 대상이 아니며 기존 그대로 동작해야 한다.
- (확정 문답 regression_keep 근거)

## 롤백 요지

AppShell(UIS-CMN-003) 도입을 역순으로 되돌린다: 쇼핑 라우트(#/shop/**)에서 AppShell 래핑을 제거해 각 화면(홈·상품 목록·상세·장바구니·주문서·로그인·배송지)을 셸 적용 이전 상태로 되돌리고, 헤더·GNB 탭·좌측 퀵바·우측 레일·하단 탭바·푸터 컴포넌트를 라우트에서 분리한다. DB·백엔드 변경이 없으므로(확정 문답 db_ripple·db_migration 근거) 데이터 롤백은 불필요하며, 부팅 리다이렉트(/shop → #/shop) 규약과 기존 주문 목록 라우트(#/, #/orders/*)는 애초에 셸 적용 대상이 아니었으므로 영향받지 않는다.
