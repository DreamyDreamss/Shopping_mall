# SR-334 — 데모 운영 데이터 시드 — 데모 회원·주문 이력(리뷰 제외)

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N26 · 에픽 비기능 · 유형 DB+배치 · Wave 2
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

마이쇼핑·관리자·랭킹·특가 베스트가 빈 화면이 아니도록 데모 회원 5명(등급 고루)과 여러 상태의 주문 30건 안팎을 멱등 시드로 만든다(데이터 파일→적재기, SQL 하드코딩 금지). 리뷰·평점은 만들지 않는다.

## 배경

베스트·랭킹(N13·N29)은 판매량이 필요하고 마이페이지·관리 화면은 상태별 주문이 있어야 확인할 수 있다. SR-304의 '가짜 후기를 만들지 않는다' 결정은 유지한다.

## 범위

- 포함:
  - 데모 회원(비밀번호 규칙 준수·해시 저장), 주문·주문 항목·상태 이력(N17 상태 고루), 결제(N19 APPROVED) 행, lab 프로파일에서만 적재, 재적재 멱등, 데모 계정 목록을 랩 문서에 기록.
- 제외:
  - 리뷰·Q&A 데이터, 운영 프로파일 적재.

## 수용 기준

- [ ] lab 프로파일 기동 시 데모 회원으로 로그인해 마이페이지에서 상태별 주문을 볼 수 있다
- [ ] 재적재해도 행 수가 늘지 않는다
- [ ] 리뷰·평점 테이블에는 행이 생기지 않는다
- [ ] 통합 테스트가 데모 데이터에 의존하지 않는다(테스트 자체 픽스처 유지)
