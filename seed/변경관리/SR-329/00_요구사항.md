# SR-329 — 약관·정책·사업자 정보 페이지와 404 화면

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N21 · 에픽 UI/UX · 유형 화면 · Wave 1
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

푸터 링크가 실제로 열리게 이용약관·개인정보처리방침·배송/교환/반품 안내·사업자 정보 페이지를 만들고, 없는 경로는 KT알파쇼핑형 404('이용에 불편을 드려 죄송합니다.' + [홈으로][돌아가기])로 보낸다.

## 배경

SR-302 푸터는 링크 영역만 있고 도착 페이지가 없다. 상품 상세 '배송·반품' 탭과 주문서 약관 동의도 같은 본문을 참조해야 한다.

## 범위

- 포함:
  - 정적 페이지 4종(본문은 랩용 예시 문구, 시행일·버전 표기), 푸터·상세 탭·주문서 약관 링크 연결, SPA 404 화면과 서버 딥링크 폴백의 알 수 없는 경로 처리.
- 제외:
  - 약관 동의 이력(후속), 공지·FAQ(SR-287), 관리자 편집.

## 수용 기준

- [ ] 푸터 링크 4개가 모두 해당 페이지를 연다
- [ ] 존재하지 않는 /shop 하위 경로는 공통 ErrorState 규격의 404 화면을 보이고 [홈으로]·[돌아가기]가 동작한다
- [ ] 상품 상세 구매정보 탭의 배송·반품 안내가 같은 본문을 참조한다
- [ ] 페이지마다 문서 제목(title)이 설정된다

## 선행 SR

- SR-311, SR-310
