### 확정된 요건 문답 9건 — 이대로 구현한다(재해석 금지)
- **이번 SR에서 하는 것과 명시적으로 빼는 것은 무엇인가?** — 포함: 주문 목록 화면(UIS-ORD-001 주문목록)에서 배송 상태로 주문을 걸러 볼 수 있어야 합니다. 현재는 전체 주문만 보여 주어 배송 지연 건을 찾으려면 눈으로 훑어야 합니다. 주문 조회 API(INF-ORD-001)에 status 필터 파라미터를 더하고, orders 테이블(SCH-ORD-001)의 배송 상태 컬럼으로 조회합니다. 기존 전체 조회 동작은 그대로 유지해야 합니다. / 제외: 요구 본문에 적히지 않은 것 전부
- **반드시 유지돼야 하는 기존 동작(회귀 범위)은 무엇인가?** — 기존 조회 결과 전부
- **기존 클라이언트와의 하위호환이 필요한가?** — 필요 — 필드 추가만(기존 호출 그대로 동작)
- **오류 응답 계약(코드·메시지)은 무엇인가?** — 400 INVALID_STATUS(허용 외 상태값) · 200 빈 배열(결과 없음)
- **타 도메인 테이블·집계(정산·통계류)에 파급이 있는가?** — 없음 — 정산 배치는 주문 상태를 읽지 않음(재답변 검증)
- **기존 데이터 이관·백필이 필요한가?** — 불필요(신규 데이터만)
- **변경 대상 화면이 전부 나열됐는가? (누락 화면 없음 확인)** — 나열된 화면이 전부: UIS-MBR-002, UIS-ORD-001 주문 목록, UIS-ORD-002, UIS-ORD-003, UIS-ORD-004, UIS-ORD-005, UIS-ORD-007, UIS-ORD-008, UIS-ORD-009, UIS-ORD-010, UIS-ORD-011, UIS-ORD-012
- **빈 값·오류 상태의 화면 표기는 무엇인가?** — 조건에 맞는 주문 없음 안내 문구 표시
- **이 화면에 어디서 들어오는가? (진입점이 이번 범위에 포함되는가)** — 기존 화면에서 이동(주문 목록 상단 필터 바)
