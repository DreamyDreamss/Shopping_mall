# SR-349 — [기능점검A] 주문 목록 배송 상태 필터

> 생성: 2026-09-20 · 출처: 로컬(SpecLens)

## 요구 요지

주문 목록 화면(UIS-ORD-001 주문목록)에서 배송 상태로 주문을 걸러 볼 수 있어야 합니다.
현재는 전체 주문만 보여 주어 배송 지연 건을 찾으려면 눈으로 훑어야 합니다.
주문 조회 API(INF-ORD-001)에 status 필터 파라미터를 더하고, orders 테이블(SCH-ORD-001)의
배송 상태 컬럼으로 조회합니다. 기존 전체 조회 동작은 그대로 유지해야 합니다.
