# SR-337 — 랭킹 페이지 — 카테고리별 판매 랭킹

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N29 · 에픽 전시 · 유형 화면+API · Wave 2
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

KT알파쇼핑형 랭킹 전용 페이지(/shop/ranking)를 만든다: 대분류 9개 탭·기간(일간·주간·월간), 순위 번호가 올라간 썸네일, 순위 변동(NEW·상승·하락), 상위 100. 카테고리 서랍의 랭킹 TOP10 가로 레일과 홈 랭킹 섹션도 같은 API를 쓴다.

## 배경

홈 랭킹 섹션(SR-302)은 응답 순서·가격으로 단순 계산한 흉내다. 판매 데이터(데모 시드)가 생기면 실제 기준으로 보여 줄 수 있다. 벤치마크 GNB '랭킹'·카테고리 서랍 'TOP10'이 이 페이지를 참조한다.

## 범위

- 포함:
  - GET /api/rankings(categoryId·period, 상위 100), 순위 변동 계산, 랭킹 페이지, 카테고리 서랍 TOP10 레일·홈 랭킹 섹션 교체.
- 제외:
  - 조회수·좋아요 가중(행동 로그 이후), 실시간 갱신, 개인화.

## 수용 기준

- [ ] 기간·카테고리를 바꾸면 순위가 취소 제외 판매 수량 순으로 다시 계산된다(동률은 최근 판매 순)
- [ ] 이전 기간에 없던 상품은 'NEW'로, 나머지는 상승·하락 폭으로 표시된다
- [ ] 판매 이력이 없는 카테고리는 빈 상태 안내를 보인다
- [ ] 홈 랭킹 섹션이 같은 API 결과의 상위 N개를 보인다
