# SR-303 — 상품 목록(검색·카테고리) 화면 신규 — 필터·정렬·페이지

> 생성: 2026-09-16 · 출처: 로컬(SpecLens)

## 요구 요지

## 요구 요지

상품을 찾는 화면을 만든다. 구성: 상단 검색 입력(키워드), 좌측 또는 상단 필터(재고 있는 상품만, 가격대 입력), 정렬 선택(추천순·낮은 가격순·높은 가격순), 결과 개수 표시, 상품 그리드(홈과 같은 상품 카드 재사용), 페이지 이동. 상태별 화면을 모두 정의한다: 로딩 중, 결과 없음(검색어 안내), 조회 실패(재시도 버튼), 마지막 페이지.

데이터는 GET /api/products 의 keyword·inStock 파라미터를 쓰고, 정렬·페이지는 응답을 화면에서 처리한다(API 계약 변경 없음).

## 범위

- 대상 화면/API/테이블(짐작 가능한 만큼): shop-web 신규 화면(`/shop/products`), 검색·필터·정렬 부품, GET /api/products
- 상품 카드 클릭 시 상품 상세로 이동(경로만 연결, 상세 화면은 별도 SR)

## 제약·유의

- 기존 API 계약·응답 형식 변경 없음, 기존 화면 동작 불변
- 부품마다 스토리(로딩·결과없음·조회실패·품절 포함), 부품 직접 fetch 금지
