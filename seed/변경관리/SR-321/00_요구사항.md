# SR-321 — 홈 리스킨·섹션 데이터화 — 기획전 배너·혜택 아이콘·MD's Pick·주요 매장·특가 베스트

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N13 · 에픽 전시 · 유형 화면+API+DB · Wave 1
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

SR-302 홈을 KT알파쇼핑 홈 순서로 리스킨하고 하드코딩(배너·카테고리 아이콘)을 서버 데이터로 바꾼다: ① 기획전 배너 캐러셀(카피 2줄+혜택 문구) ② 지금 방송중 레일 자리 ③ 혜택 아이콘 줄 ④ MD's Pick(가운데 강조 캐러셀) ⑤ 풀폭 기획 배너 ⑥ 최근 본 상품 ⑦ 주요 매장 바로가기(원형 썸네일) ⑧ 특가 베스트. GET /api/home 한 번으로 받는다.

## 배경

shopStatic.ts의 BANNER_SLIDES·CATEGORY_SHORTCUTS는 상수다. 벤치마크 §2의 섹션 구성을 운영 데이터 모양(섹션+항목)으로 옮긴다. SR-236(타임딜·개인화·관리자 섹션 편집)은 선행이 많아 데이터화 기반만 먼저 분리하고, SR-273이 이 테이블의 편집 화면을 만든다.

## 범위

- 포함:
  - DISPLAY_SECTIONS(section_id, section_type BANNER/BENEFIT_ICONS/MD_PICK/WIDE_BANNER/SHOP_SHORTCUTS/SPECIAL_BEST, title, sort_order, start_at, end_at, use_yn) + DISPLAY_SECTION_ITEMS(section_id, seq, image_url, title, subtitle, link_url, sku), 전시 시드는 카탈로그와 같은 매니페스트 방식(데이터 파일→적재기, SQL 하드코딩 금지, 배너 이미지도 외부 경로 서빙 규칙), GET /api/home(공개), 홈 리스킨·바인딩, 비어 있거나 기간 밖 섹션은 숨김.
- 제외:
  - 지금 방송중 레일 내용(방송 편성 SR), 특가쇼 매장(SR-270), 개인화 추천(SR-236 잔여), 섹션 편집 화면(SR-273), 진입 팝업.

## 수용 기준

- [ ] 홈이 shopStatic.ts의 배너·카테고리 상수를 더 이상 참조하지 않는다
- [ ] 섹션 순서가 sort_order대로이고 기간 밖·use_yn=N 섹션과 항목은 응답에 없다
- [ ] 배너 캐러셀이 자동 넘김·좌우 이동·n/N 표시를 유지한다(SR-302 동작 유지)
- [ ] 주요 매장·혜택 아이콘 링크가 존재하는 화면으로 이어지거나, 도착 화면이 없는 항목은 노출되지 않는다
- [ ] 섹션 데이터가 비면 섹션 제목까지 숨겨진다
