# SR-208 — 주문 목록 오류 상태 표시 정리 + 400 사유 문구 개선

> 생성: 2026-09-08 · 출처: 로컬(SpecLens)

## 요구 요지

주문 목록 화면(`order/list.html`)에서 조회가 4xx로 실패해 오류 배너가 표시될 때는, "조회 결과 없음" 안내·"전체 N건" 총건수 라벨·결과 테이블을 모두 숨겨 오류 상태와 빈 결과 상태를 화면에서 구분한다. 함께 `OrderService.list`의 400 사유 문구를 개선해, 종료일만 입력한 경우 사용자가 입력한 적 없는 서버 계산 시작일을 사유로 제시하지 않고 기본값(최근 30일) 적용 사실과 취할 행동을 안내한다. 5xx는 이번에도 흡수하지 않으며 그대로 전파한다(Critical Rule 1 유지). `cart/list.html`·`product/detail.html`의 동일 패턴 표준화는 이번 범위에서 제외하고 별도 SR로 다룬다.
