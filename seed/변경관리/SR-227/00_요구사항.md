# SR-227 — 주문 목록 상단 주문 요약 카드 신설

> 생성: 2026-09-11 · 출처: 로컬(SpecLens)

## 요구 요지

주문 목록 화면(UIS-ORD-001) 그리드 위에 조회 결과의 요약 카드(OrderSummaryCard)를 새로 둔다 — 전체 건수, 총 주문금액, 상태별 건수. 조회 결과가 0건이면 카드는 '집계할 주문이 없습니다'를, 조회 실패면 카드도 숨긴다(그리드와 같은 규칙). shop-web 신규 화면 부품이며 API·DB는 손대지 않는다.
