# SR-306 — 상품 정가·대표 이미지 데이터 추가 — 쇼핑 화면이 할인·이미지를 실제로 표시

> 생성: 2026-09-17 · 출처: 로컬(SpecLens)

## 요구 요지

## 요구 요지

쇼핑 화면이 상용 몰처럼 보이려면 상품에 정가와 대표 이미지가 있어야 하는데 지금 products 테이블·조회 응답에는 판매가(price)와 재고만 있다. 정가(list_price)와 대표 이미지 경로(image_url)를 테이블과 조회 응답에 더하고, 시드 데이터를 채운다. 할인율은 저장하지 않고 정가와 판매가로 화면이 계산한다(정가가 없으면 할인 표시를 하지 않는다).

## 범위

- 대상: products 테이블 컬럼 2개 추가(list_price·image_url, 둘 다 NULL 허용), 상품 목록·단건 조회 응답에 두 필드 추가, 시드 데이터 갱신, 쇼핑 홈 화면이 그 값을 받아 정가 취소선·할인 배지·이미지를 표시
- 이미지는 외부 URL이 아니라 앱이 서빙하는 정적 경로(/shop 자산 또는 /images)로 둔다

## 제약·유의

- 기존 응답 필드·순서는 그대로 두고 **필드 추가만**(하위호환)
- 값이 없는 상품은 지금처럼 이니셜 대체 영역·할인 배지 없음으로 보인다(빈 값이 화면을 깨뜨리지 않는다)
- 기동 DDL은 IF NOT EXISTS만(DROP 금지), 새 SQL 파일은 다음 번호로
- 상용 사이트의 상품 이미지·문구를 쓰지 않는다(자체 제작 또는 단색 대체 이미지)
