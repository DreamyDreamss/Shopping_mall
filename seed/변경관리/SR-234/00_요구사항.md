- **Q. 오류 응답 계약(코드·메시지)은 무엇인가?**
  - A. 기존 오류 계약(코드 MBR-4xxx + message) 그대로. 만료 링크/코드는 410 MBR-4101 '만료됨 — 다시 요청', 존재 여부는 새지 않게 요청 API는 항상 202 (viewer · 2026-09-13 08:39)

<!-- clarify:db_ripple -->
- **Q. 타 도메인 테이블·집계(정산·통계류)에 파급이 있는가?**
  - A. MEMBER_PASSWORD_RESETS 테이블 신설(대상 email/phone_norm · 코드 해시 · 만료 시각 · 소비 시각 · 시도 횟수 · 생성 시각) + MEMBERS.password_hash 갱신·updated_at. 기존 컬럼 의미 변경 없음 (viewer · 2026-09-13 08:39)

- **Q. 기존 데이터 이관·백필이 필요한가?**
  - A. Flyway V4__member_password_resets.sql — CREATE TABLE IF NOT EXISTS(랩 규칙 ddl-idempotent). 기존 행 이행 없음 (viewer · 2026-09-13 08:39)

- **Q. 이 변경으로 생기거나 바뀌는 화면 상태 중 스토리(상태별 실물)로 남길 것은 무엇인가?**
