# SR-344 — 하이라이트 숏폼 — 방송 클립 카드·상품 연결

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N36 · 에픽 방송 · 유형 화면+API+DB · Wave 3
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

편성표·상세에 방송 하이라이트 숏폼(세로 영상 카드, 탭하면 재생)을 노출하고 클립마다 연결 상품으로 이동한다.

## 배경

벤치마크 §3 편성표의 '하이라이트 숏폼'. 영상 파일도 이미지와 같은 사내 로컬 자산 규칙을 따른다.

## 범위

- 포함:
  - BROADCAST_CLIPS(clip_id, broadcast_id, sku, video_url, poster_url, duration_sec, sort_order), 클립 파일은 외부 경로 설정(shop.media-location)으로 서빙·저장소 미포함, 클립 목록 API, 편성표 숏폼 레일·상세 미디어 캐러셀 연결, 자동재생 없음(탭 재생)·음소거 기본.
- 제외:
  - 영상 업로드·인코딩, 라이브 스트리밍, 좋아요·댓글.

## 수용 기준

- [ ] 클립 카드를 누르면 영상이 재생되고 연결 상품 버튼으로 상세에 간다
- [ ] 영상 파일이 없으면 포스터 이미지만 보이고 오류가 나지 않는다
- [ ] 영상 파일이 git 추적 대상이 아니다
- [ ] 키보드로 재생/정지할 수 있다

## 선행 SR

- SR-320, SR-317

## 제약·유의

- KT알파쇼핑 상품 이미지·디자인 자료는 사내 로컬 테스트베드 한정(외부 배포·공개 저장소 반입 금지) — 이미지는 모듈 git에 넣지 않는다.
- 기존 종결 SR의 확정 결정을 뒤집을 때는 확정 문답에 사유를 남긴다.
