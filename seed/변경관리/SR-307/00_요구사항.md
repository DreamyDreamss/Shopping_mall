# SR-307 — 상품 조회를 공개 경로로 — 앱 서빙 쇼핑 화면에서 401 해소(GET만)

> 생성: 2026-09-17 · 출처: 로컬(SpecLens)

## 요구 요지

## 요구 요지

앱이 서빙하는 쇼핑 화면(/shop)에서 상품 조회가 401로 막힌다. 브라우저는 API 키를 보내지 않는데 ApiKeyAuthFilter가 모든 /api/**에 키를 요구하기 때문이다(개발 서버는 프록시가 키를 넣어 줘서 가려져 있었다). 로그인 없이 볼 수 있어야 하는 **읽기 전용 상품 조회**만 공개 경로로 연다.

## 범위

- 대상: ApiKeyAuthFilter의 공개 경로에 GET 상품 목록·단건 조회 추가. GET 메서드일 때만 공개하고 다른 메서드는 지금처럼 막는다
- 공개 대상은 판매중 상품 정보에 한정한다(회원·주문·장바구니·관리자 경로는 그대로 인증 필요)

## 제약·유의

- 회원·주문·장바구니·CSV 등 기존 보호 경로의 인증 동작 불변(회귀 테스트로 확인)
- 공개 응답에 회원 식별자·재고 원가 같은 내부 정보가 새로 들어가지 않는다(지금 응답 그대로)
- 공개 경로라도 쓰기(POST/PATCH/DELETE)는 반드시 인증
- 레이트리밋·캐시 정책은 이번 범위 밖
