# SR-336 — 브랜드관 — 브랜드 헤더·브랜드 상품·브랜드 위크(정관장형)

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N28 · 에픽 전시 · 유형 화면+API · Wave 2
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

GNB '정관장(브랜드위크)'처럼 브랜드 전용 매장을 만든다: /shop/brands/{id}에 브랜드 배너·로고·소개, 브랜드 상품 그리드(정렬·카테고리 칩), 브랜드 기획 배너 자리. GNB에 노출할 대표 브랜드관 1개를 설정값으로 지정한다.

## 배경

벤치마크 GNB의 브랜드관(정관장 브랜드위크)과 홈 '주요 매장'의 브랜드위크 바로가기가 도착할 곳이 필요하다. 상품 카드·상세의 브랜드명도 여기로 온다.

## 범위

- 포함:
  - GET /api/brands/{id}(배너·로고·상품 수), 브랜드관 화면(목록 API brandIds 재사용), 카드·상세 브랜드명 링크, GNB 대표 브랜드관 탭.
- 제외:
  - 브랜드 쿠폰(SR-269 이후 자리만), 브랜드 기획전 편집(SR-241·273), 브랜드 관리(관리자 카테고리·브랜드 SR), 브랜드 팔로우.

## 수용 기준

- [ ] 상품 카드·상세의 브랜드명을 누르면 해당 브랜드관으로 간다
- [ ] 브랜드관 상품 수가 목록 API의 해당 브랜드 판매중 상품 수와 같다
- [ ] GNB 대표 브랜드관 탭이 설정된 브랜드관을 연다
- [ ] 사용 중지 브랜드의 브랜드관은 404 화면을 보인다
