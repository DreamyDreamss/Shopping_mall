# SR-309 — 디자인 토큰·Pretendard 도입 — KT알파쇼핑 톤(색·타이포·간격·radius·그림자)

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N01 · 에픽 UI/UX · 유형 화면 · Wave 1
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

쇼핑 SPA 전 화면이 공유할 디자인 토큰(CSS 변수)과 Pretendard 웹폰트(저장소 번들)를 도입한다. 값은 KT알파쇼핑 실측 톤을 따른다: 본문 #101010·14px, 보조 #767676/#AAAAAA, 면 #F2F2F2/#F5F5F5/#F9F9F9, 포인트 보라 #713FC5(배경 #F2EBFF), 링크 파랑 #177BC3, 할인·가격 빨강 #FF5259, 브랜드 레드 #ED1C24, 딤 rgba(16,16,16,.3).

## 배경

지금 shop-web은 화면마다 색·글자 크기·여백을 따로 적어 상용 몰처럼 보이지 않는다. 테스트베드의 목표 모습은 KT알파쇼핑이다(사용자 회사 사이트, 사내 로컬 테스트베드에 한해 디자인·구성 사용 허락 — 벤치마크 {{WS}}\_lab\plan\benchmark_ktalpha.md). 이후 모든 화면 SR이 같은 토큰을 쓰게 하려면 토큰이 먼저 있어야 한다. SR-289 본문의 '디자인 토큰'을 이 SR로 분리한다.

## 범위

- 포함:
  - 색 토큰(위 실측값 + 상태색 성공/경고/오류/정보), 그라데이션 토큰 2종(파랑→보라: 구매 버튼·헤더 토글, 보라→파랑: 최근 본 상품 헤더), 타이포(Pretendard, 본문 14px 기준 크기 스케일 8단·굵기 3종·배너 카피용 굵은 헤드라인 40px대), 간격 4px 배수, radius(카드 썸네일 8px 포함 3종), 그림자 3종, z-index 층, 레이아웃 폭(본문 750px 단일 컬럼), Pretendard woff2 서브셋 저장소 번들(OFL)·font-display: swap, 스토리북 Tokens 페이지.
- 제외:
  - 기존 화면 교체(리스킨 SR·각 화면 SR), 다크 모드, 컴포넌트(다음 SR), 앱 셸.

## 수용 기준

- [ ] 토큰은 CSS 변수 한 파일에 정의되고 새 스타일 코드는 하드코딩 색·px 대신 토큰을 참조한다(새 파일의 하드코딩 색 0건 검사)
- [ ] 색 토큰 값이 벤치마크 실측값(#101010·#713FC5·#FF5259·#177BC3 등)과 일치한다
- [ ] 본문 텍스트 토큰과 배경 조합의 명도 대비가 4.5:1 이상이며 대비 표가 토큰 문서에 있다(미달 조합은 본문 사용 금지로 표기)
- [ ] 웹폰트는 외부 CDN 없이 앱이 서빙하는 정적 경로에서 로드되고 실패 시 시스템 한글 폰트로 대체된다
- [ ] 기존 화면의 동작과 테스트가 그대로 통과한다
