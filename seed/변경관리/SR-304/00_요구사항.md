# SR-304 — 상품 상세 화면 신규 — 이미지·가격·수량·장바구니·탭 구성

> 생성: 2026-09-16 · 출처: 로컬(SpecLens)

## 요구 요지

## 요구 요지

상품 상세 화면을 만든다. 구성: ① 상단 좌측 이미지 영역(대표 이미지+썸네일 목록, 이미지 없으면 대체 영역) ② 우측 정보 영역(상품명, 판매가·정가·할인율, 재고 상태, 수량 선택, [장바구니 담기]·[바로 구매]) ③ 탭 영역(상세정보 / 구매정보 / 상품평 / 상품문의) ④ 상품정보제공고시 표(항목명-값 2열) ⑤ 함께 보면 좋은 상품 가로 레일. 상품평·문의 탭은 데이터가 없으므로 "준비 중" 빈 상태로 둔다(가짜 후기를 만들지 않는다).

데이터는 GET /api/products/{sku} 와 POST /api/cart/items 를 쓴다. 장바구니 담기 성공 시 상단 장바구니 수량이 즉시 늘어야 한다.

## 범위

- 대상 화면/API/테이블(짐작 가능한 만큼): shop-web 신규 화면(`/shop/products/{sku}`), 상세 부품, GET /api/products/{sku}, POST /api/cart/items
- 없는 상품 코드로 들어오면 안내 화면(목록으로 돌아가기)

## 제약·유의

- 기존 API 계약 변경 없음(응답 필드 추가 요구도 하지 않는다 — 없는 값은 화면에서 감춘다)
- 품절 상품은 담기·구매 버튼을 비활성으로 두고 사유를 보여 준다
- 부품마다 스토리(기본·품절·이미지없음·담기실패·상품없음), 부품 직접 fetch 금지

- **Q. 이번 SR에서 하는 것과 명시적으로 빼는 것은 무엇인가?**
  - A. 포함: 상품 상세 화면 신규(경로 /shop/products/{sku}) — 이미지 영역(대표+썸네일·없으면 대체), 정보 영역(상품명·판매가·정가·할인율·재고 상태·수량 선택·[장바구니 담기]·[바로 구매]), 탭(상세정보·구매정보·상품평·상품문의 — 상품평/문의는 데이터가 없어 '준비 중' 빈 상태), 상품정보제공고시 표, 함께 보면 좋은 상품 레일. 제외: 리뷰·문의 기능 구현(데이터 없음), 결제, 옵션(단일 SKU 기준). (viewer · 2026-09-16 23:59)

- **Q. 반드시 유지돼야 하는 기존 동작(회귀 범위)은 무엇인가?**
  - A. 특정 화면/API만: 기존 주문 목록·상세·로그인·비밀번호 재설정 화면과 그 동작 불변 · /api/** 요청·응답·인증(X-Api-Key)·오류 계약 불변 · 기존 Thymeleaf 화면 경로 불변. 장바구니 담기는 기존 POST /api/cart/items 계약 그대로 쓴다. (viewer · 2026-09-16 23:59)

- **Q. 기존 클라이언트와의 하위호환이 필요한가?**

- **Q. 오류 응답 계약(코드·메시지)은 무엇인가?**
  - A. 새 오류 코드 없음. 없는 상품(404)은 '상품을 찾을 수 없습니다 + 목록으로' 화면 · 담기 실패는 사유 문구와 재시도 · 품절은 담기/구매 비활성. (viewer · 2026-09-16 23:59)

- **Q. 빈 값·오류 상태의 화면 표기는 무엇인가?**
  - A. 이미지 없음 → 대체 영역 · 상품평·문의 → '준비 중' · 고지 항목 값 없음 → '-' · 상품 없음 → 안내 화면 · 조회 실패 → 다시 시도 · 품절 → 배지와 버튼 비활성 사유. (viewer · 2026-09-16 23:59)
