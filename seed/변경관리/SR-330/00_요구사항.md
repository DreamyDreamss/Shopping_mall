# SR-330 — 비회원 장바구니 — 로컬 담기와 로그인 시 병합

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N22 · 에픽 장바구니 · 유형 화면+API · Wave 2
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

비로그인 사용자도 장바구니에 담을 수 있게 브라우저에 보관하고, 로그인 순간 서버 장바구니와 병합한다(같은 sku는 수량 합산·재고 상한 보정).

## 배경

지금 cart_items는 member_id 키라 로그인 전에는 담기가 막힌다. 상용 몰은 둘러보며 담고 결제 직전에 로그인시킨다.

## 범위

- 포함:
  - 로컬 장바구니 저장(최대 50품목), POST /api/cart/merge(본인만, 재고 초과분 보정 결과 반환), 로그인·가입 직후 병합 1회, GNB 수량 배지가 로컬/서버를 일관 표시.
- 제외:
  - 비회원 주문(SR-263), 판매자별 묶음(SR-251).

## 수용 기준

- [ ] 비로그인 담기 후 로그인하면 로컬 품목이 서버 장바구니에 합쳐지고 로컬은 비워진다
- [ ] 같은 sku는 수량이 합산되며 재고를 넘으면 재고까지만 담기고 안내가 보인다
- [ ] 병합 요청이 두 번 들어와도 수량이 두 배가 되지 않는다(멱등)
- [ ] 기존 장바구니 API 계약이 불변이다
