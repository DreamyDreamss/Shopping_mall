# SR-317 — 상품 상세 데이터 연결 — 미디어 캐러셀·상세 설명 이미지·고시·태그·브레드크럼

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N09 · 에픽 상품 · 유형 화면+API · Wave 1
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

상품 상세가 카탈로그 데이터를 실제로 쓰게 한다: 미디어 캐러셀은 PRODUCT_IMAGES(MAIN·EXTRA·VIDEO), 상세정보 탭은 DETAIL 이미지와 요약·원산지, 구매정보 탭은 고시 표, 태그 줄은 PRODUCT_TAGS(누르면 검색), 브랜드명은 브랜드관 링크, '비슷한 상품을 추천해요' 레일은 같은 소분류.

## 배경

SR-304의 고시 표(productNoticeItems.ts)와 썸네일은 화면 상수·대표 이미지 1장으로 채워져 있다. SR-244의 데이터 부분을 분리한 것이다.

## 범위

- 포함:
  - 상세 화면 데이터 바인딩, 데이터 없을 때 상태(이미지 0장·고시 0항목·설명 없음), 태그→검색 이동, 관련 상품 레일 교체, 브레드크럼(대>중>소).
- 제외:
  - 레이아웃, 옵션(SR-245), 방송 정보, 도착 예정일(SR-244 잔여), 리뷰·문의(SR-246·247).

## 수용 기준

- [ ] 미디어 캐러셀 장수가 PRODUCT_IMAGES MAIN+EXTRA+VIDEO 수와 같고 영상은 재생 컨트롤이 있다
- [ ] 고시 표가 화면 상수(productNoticeItems.ts) 없이 API 값으로 그려지고 0항목이면 '판매자 제공 정보 없음'을 보인다
- [ ] 태그를 누르면 그 태그 키워드로 검색 결과가 열린다
- [ ] 관련 상품 레일은 같은 소분류의 다른 판매중 상품만 보인다(자기 자신 제외)
