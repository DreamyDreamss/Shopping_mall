# SR-318 — TV상품·무이자 할부 표기 — 상품 속성·카드사 무이자 안내

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N10 · 에픽 상품 · 유형 화면+API+DB · Wave 1
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

홈쇼핑 상품의 핵심 표기를 데이터로 만든다: 상품 속성 tv_product_yn(TV상품 배지)·max_installment_months(무이자 최대 N개월), 카드사별 무이자 개월 테이블과 '무이자할부 보기' 팝업. 카드·상세·방송 레일이 같은 값을 표시한다.

## 배경

벤치마크의 상품 카드와 상세에는 'TV상품'·'무이자 N' 배지가 붙는다. 지금은 원천 데이터가 없다. 실제 할부 결제는 PG 영역이라 여기서는 표기·안내까지만 한다.

## 범위

- 포함:
  - PRODUCTS 컬럼 2개 추가(NULL 허용), CARD_INSTALLMENT_PROMOS(card_company, min_amount, max_months, start_at, end_at) — 시드는 데이터 파일 적재, 상품 응답에 tvProduct·maxInstallmentMonths 추가, 상세 '무이자할부 보기' 팝업(카드사·개월·최소 금액), 카탈로그 적재기가 선택 필드를 읽음, 카드·상세 배지 연결.
- 제외:
  - 할부 결제 처리(모의 결제는 일시불 기준, SR-256 잔여), 청구할인, 무료배송 배지 원천(SR-308·268).

## 수용 기준

- [ ] tv_product_yn=Y 상품만 카드·상세에 'TV상품' 배지가 보인다
- [ ] 무이자 개월이 있는 상품은 '무이자 N'(테두리형) 배지가 보이고 없으면 배지가 없다
- [ ] '무이자할부 보기'가 기간 안의 카드사 행만 보여 주고 판매가가 최소 금액 미만인 카드사는 '적용 불가'로 표시한다
- [ ] 상품 응답에 필드 추가 외 변경이 없다
