### 장바구니 API (신규 — D3)
| 엔드포인트 | 동작 | 성공 | 오류 |
|-----------|------|------|------|
| POST /api/cart/items | 담기 {memberId, sku, qty} — 같은 상품 합산 | 200 품목 | 400/404/409(재고·품절, 사유) |
| GET /api/cart?memberId= | 조회 | 200 {items[{sku,productName,price,qty,lineTotal}], totalAmount} | 404(회원) |
| PATCH /api/cart/items/{sku}?memberId= | 수량변경 {qty} | 200 품목 | 400(qty<1)/404/409(재고) |
| DELETE /api/cart/items/{sku}?memberId= | 삭제 | 204 | 404 |

## 재고 의미(중요)
담기는 재고를 **차감하지 않는다**(보관일 뿐). 차감은 주문 전환(SR-203) 몫. 단 담기·수량변경
시점의 재고 초과는 거부(사용자 혼란 방지) — 시점 차로 초과가 될 수 있음은 SR-203에서 재검증.
