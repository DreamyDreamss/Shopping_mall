# SR-341 — 판매자(입점사) 마스터 — 판매자 테이블·상품 귀속

> 생성: 2026-09-19 · 출처: 로컬(SpecLens) · 계획 `_lab/plan/new_srs.json` N33 · 에픽 관리자 · 유형 API+DB · Wave 3
> 벤치마크: KT알파쇼핑 — `_lab/plan/benchmark_ktalpha.md`(스크린샷 `_lab/plan/bench/`), 전체 계획 `_lab/plan/ECOMMERCE_PLAN.md`

## 요구 요지

SELLERS(seller_id, seller_name, 기본 배송비, 무료배송 기준, 반품지, 정산 수수료율)를 만들고 상품을 판매자에 귀속한다. 기본 판매자 1곳(자사) + 입점 샘플 2~3곳.

## 배경

SR-251(판매자별 묶음), SR-268(판매자별 배송비), SR-284(판매자 정산)는 모두 판매자 개념을 전제로 하는데 판매자 테이블이 어디에도 없다.

## 범위

- 포함:
  - SELLERS 테이블·시드, products.seller_id(기본값=자사), 상품 조회 응답에 seller 추가, 매니페스트 적재(N06)에 판매자 필드 선택 지원.
- 제외:
  - 판매자 가입·판매자 센터, 묶음·배송비 계산(SR-251·268), 정산(SR-284).

## 수용 기준

- [ ] 모든 상품이 판매자를 하나 가지며 기존 상품은 자사로 채워진다
- [ ] 상품 응답에 seller{id,name}가 추가되고 기존 필드는 불변이다
- [ ] 기존 장바구니·주문 흐름이 그대로 동작한다
