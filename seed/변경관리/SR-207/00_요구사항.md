# SR-207 — 회원 최근 주문 5건 화면(마이페이지 신규)

> 생성: 2026-09-07 · 출처: 로컬(SpecLens)

## 요구 요지

회원 상세(마이페이지) 화면을 신규로 만들고, 그 회원의 최근 주문 5건(주문번호·일시·상태·금액)을 최신순으로 표시한다. 주문이 없으면 "최근 주문 없음"을 표시한다. 데이터는 기존 회원 상세 API(INF-ORD-002)의 recentOrders를 그대로 쓴다 — API 응답 계약은 바꾸지 않는다. 취소 주문도 포함(현행 규칙 유지). 주문번호 클릭 시 주문 상세(UIS-ORD-002)로 이동. 권한은 SR-204 전역 정책 그대로(관리 자원).
