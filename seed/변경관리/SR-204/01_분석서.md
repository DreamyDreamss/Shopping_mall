# SR-204 분석서 — API 인증·반출 통제 도입

## AS-IS
- 전 API 무인증(랩 전제). memberId를 요청 본문/파라미터로 **신뢰**(IDOR — SR-203·LAB-104 QA
  이월). [[INF-ORD-003]]은 401을 기재하나 실재하지 않음(선행 문서 드리프트).
- /api/orders/export 행 상한 없음(무인증 대량 반출 — LAB-104 QA 지적).

## TO-BE (요구·D13)
- `/api/**` 전역 **X-Api-Key 인증**(401). 키 2종: admin(전 회원)·member(자기 자원만 — 403 IDOR 차단).
- export **행 상한 1000**(초과 시 413 + 사유 — 계약 신설).
- 화면(뷰 컨트롤러)은 **무인증 유지**(데모 접근성 — D13), CSRF는 **범위 제외**(D13 근거: API가
  헤더 키 인증이라 브라우저 자동 크리덴셜 부재 → CSRF 성립 전제 약함. 화면 인증 도입 시 재검토).
