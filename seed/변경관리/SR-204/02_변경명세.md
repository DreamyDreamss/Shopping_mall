# SR-204 변경명세

## 1. 인증 필터 (신규 — 횡단)
- `ApiKeyAuthFilter`: `/api/**` 매칭, `X-Api-Key` 검증(D13 키 매핑). 401/403은 JSON 본문.
- 키 매핑: application.yml `lab.api-keys.{key}=memberId|*`. 코드에 키 하드코딩 금지.

## 2. IDOR 대조 (신규 — 필터 내)
- member 스코프 키: 요청의 memberId(쿼리·JSON 본문·경로 /api/members/{id})가 키 회원과
  다르면 403 `{"error":"forbidden"}`. admin(*) 키는 전체 통과.

## 3. export 상한 (변경 — FUNC-order-013 계약)
- OrderService.exportCsv 결과 1000행 초과 → 413(D13). CSV 조립 전에 건수 판정.

## 4. 문서 정합
- INF-ORD-003의 401 기재가 **구현으로 실재화**(드리프트 해소). 전 INF 오류 계약(401/403)은
  종결 단계 sl-sync --apply 재생성이 반영.
