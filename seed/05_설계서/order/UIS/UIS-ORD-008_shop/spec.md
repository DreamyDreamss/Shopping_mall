# UIS-ORD-008: shop

> [반영: SR-302.1] — 코드(라우트) 기준 재동기화 골격. 화면 구성·상태·검증 규칙은 보강 대상

## 1. 화면 개요

- 라우트: `/shop` (spa-route, `modules/shop-web/src/App.tsx:93`)
- 목적: 커머스 홈(메인) — GNB·히어로 배너 캐러셀·카테고리 숏컷·추천 상품 그리드·랭킹(탭 전환)·최근 본 상품(localStorage)·푸터. 로그인 없이 접근 가능(SR-302).

### 진입/라우팅 (SR-302.1 round 3 확정값)

- `/shop`·`/shop/`(서버 경로, `INF-ORD-017`) 아래로 **해시 없이 최초 진입**할 때만 `#/shop`(이 화면)으로 1회 이동한다 — `applyShopBootRedirect()`(`modules/shop-web/src/App.tsx:75-79`, 호출부 `modules/shop-web/src/main.tsx:10`, 라우터 렌더 이전 모듈 최상위 1회).
- 그 뒤 `#/`는 **언제나** 주문 목록(`UIS-ORD-001`)이다 — `/` 라우트는 리다이렉트를 거치지 않고 무조건 `OrderListPage`를 렌더한다(`modules/shop-web/src/App.tsx:86`).
- `/shop#/`(빈 해시로 재진입)와 `/shop#/shop`(이 화면)은 서로 다른 경로다 — 전자는 주문 목록, 후자만 이 화면.

## 3. 입력·검증 규칙

- 검색 입력: 제출하면 검색어를 `?keyword=`로 실어 상품 목록 화면(`UIS-ORD-009`, `/shop/products`)으로 이동한다
  — [반영: SR-303.1] 2026-09-17. 값 검증 없음(빈 검색어 제출도 이동은 함, 목록 화면이 전체를 보여줌).
- 카테고리 숏컷 클릭: 파라미터 없이 상품 목록 화면(`UIS-ORD-009`)으로 이동(전체 목록) — [반영: SR-303.1]
  2026-09-17. 카테고리 데이터·필터 API가 없어 라벨을 검색어로 대체하지 않는다(대체 시도가 시드 상품명과
  겹치지 않아 항상 빈 결과가 되는 결함이었음, round2에서 확인 후 되돌림). 실제 카테고리 필터링은 후속 SR.
- 수량·금액 입력 없음 — 이 화면은 읽기 전용이다.
- 정가·할인율: 정가가 없거나 판매가 이상이면 취소선·할인 배지를 그리지 않는다. 할인율은 내림해 정수 %로 쓴다.
- 최근 본 상품: 같은 상품은 하나로 합치고(중복 제거) 8개를 넘으면 오래된 것부터 지운다.
